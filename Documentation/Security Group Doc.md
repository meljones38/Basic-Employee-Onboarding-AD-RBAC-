# Security Group Documentation
## Finance
**Organizational Unit (OU):** Finance
**Security Group:** Finance-Users
**Purpose:** Provides Finance department users with access to Finance files, payroll systems, and department shared drives.
## HR
**Organizational Unit (OU):** HR
**Security Group:** HR-Users
**Purpose:** Provides HR department users with access to employee records, payroll systems, benefits portals, and onboarding documentation.
## IT
**Organizational Unit (OU):** IT
**Security Group:** IT-Users 
**Purpose:** Provides IT department users with access to domain administration, service desk systems, and core network configuration resources.
## Operations
**Organizational Unit (OU):** Operations
**Security Group:** Operations-Users
**Purpose:** Provides Operations department users with access to facility controls, scheduling applications, logistics resources, and shared folders.
